🏗️ Architecture Overview

Frontend (Admin) React 19 + Vite 8 + Tailwind CSS 4 — SPA dashboard for administrators
Frontend (Mobile) React Native 0.83 + Expo SDK 55 — iOS & Android cross-platform app
Backend API Express.js 5 — REST API server on port 3001
AI Server FastAPI (Python 3) + Sentence Transformers + CLIP — embedding generation on port 8000
Database Supabase (PostgreSQL) — hosted relational database with built-in storage & auth
File Storage Supabase Storage — image uploads for lost/found items
